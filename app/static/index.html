Resources & References

Overview of DoE methodologies and background literature references.

Design Types Summary

Plackett-Burman Designs
Highly efficient screening designs utilizing cyclic permutations. Ideal for identifying a few significant factors from a large set of candidates (4–23 factors) in a minimal number of runs.
Factorial Designs (Full / Fractional)
Investigate factor interactions systematically. Full factorials run all level combinations. Fractional factorials use resolution structures (III, IV, V) to significantly reduce run count while resolving primary effects.
Response Surface Designs (Box-Behnken / CCD)
Use 3 or more levels to model curvature. Box-Behnken is highly efficient for 3-level factors. Central Composite (CCD) augments factorial points with axial/center points to enable quadratic estimation.
Space-Filling Designs (Latin Hypercube)
Maximize coverage and spread runs uniformly. Crucial when factors have complex, non-linear boundaries, or when validating machine learning models.
D-Optimal Custom Designs
Algorithmic designs constructed by coordinates exchange (Fedorov's algorithm). Custom-tailored to minimize parameter variance for a user-specified regression formula.
